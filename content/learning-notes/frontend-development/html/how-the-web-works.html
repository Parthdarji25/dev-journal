How the Web Works

Every site you open follows the same journey: your browser asks a server for files, the server sends them back, and the browser turns them into the page you see.

Key ideas
  • The client (your browser) asks; the server answers.
  • A URL tells the browser where to ask.
  • DNS turns a name like example.com into an IP address.
  • HTTP is the language of the request and the response.
  • The browser builds the page from HTML (structure), CSS (style) and JavaScript (behaviour).
One page load: find the server with DNS, ask with an HTTP request, receive the files in an HTTP response.

3. DNS: finding the server

Computers find each other by IP address (like 93.184.215.14), not by name. DNS (Domain Name System) is the internet's phone book.

  1. You type example.com.
  2. The browser checks its cache, then asks a DNS resolver.
  3. The resolver finds the IP address and returns it.
  4. The browser connects to that IP.
Tip: this is why a new domain can take a while to "work". DNS records need time to spread across resolvers.

5. How the browser draws the page

  1. Parse HTML → DOM: a tree of every element on the page.
  2. Parse CSS → CSSOM: a tree of every style rule.
  3. Render tree: DOM + CSSOM, keeping only what is visible.
  4. Layout: the size and position of every element.
  5. Paint: pixels for text, colours and images.
  6. JavaScript can change the DOM or styles, which may trigger layout and paint again.
<!doctype html>
<html>
  <head>
    <link rel="stylesheet" href="style.css" />
  </head>
  <body>
    <h1>Hello</h1>
    <script src="app.js" defer></script>
  </body>
</html>
Watch out: a <script> without defer in the <head> pauses HTML parsing until it downloads and runs, so the page shows up later. Use defer or put scripts at the end of <body>.

6. See it yourself with DevTools

  1. Open any site and press F12.
  2. Network tab: reload and watch every request, its status code and size.
  3. Elements tab: the live DOM tree.
  4. Console tab: JavaScript errors and logs.

Check yourself

What does DNS do, and why is it needed?

It turns a domain name into an IP address. Computers connect by IP, but people remember names.

What is the difference between a 404 and a 500?

404: the page doesn't exist (usually a wrong URL). 500: the server crashed while handling the request.

In what order does the browser build the page?

HTML → DOM, CSS → CSSOM, render tree, layout, paint. JavaScript can trigger layout and paint again.
